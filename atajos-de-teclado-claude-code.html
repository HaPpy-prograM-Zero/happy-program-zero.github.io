Atajos de teclado de Claude Code que merece la pena aprender

Claude Code tiene una lista larga de atajos. No vas a necesitar la mayoría. Estos son los que más tiempo ahorran, agrupados por lo que estás haciendo. Pulsa ? con la caja vacía para ver la lista de tu configuración.

Parar, deshacer, salir

  • EscPara la respuesta o la llamada a una herramienta a mitad de turno para que puedas reconducir. Claude conserva el trabajo hecho hasta ese momento. En un diálogo, lo cierra.
  • Esc dos vecesCon texto en la caja, lo borra y guarda el borrador para recuperarlo con la flecha arriba. Con la caja vacía, abre el menú de rewind.
  • Ctrl+CInterrumpe una operación en marcha. Si no hay nada en marcha, la primera pulsación borra la caja y la segunda sale.
  • Ctrl+DSale. La primera pulsación muestra un aviso y una segunda enseguida sale. Con texto en la caja, borra el carácter que hay tras el cursor.
  • Ctrl+_Deshace la última edición del texto de tu petición.

Modos y modelo

  • Shift+TabRecorre los modos de permisos. En Windows, Alt+M hace lo mismo cuando tu Node o Bun no activa el modo de entrada VT.
  • Option+P / Alt+PCambia de modelo sin borrar lo que has escrito (Option en macOS, Alt en Windows y Linux).
  • Option+O / Alt+OActiva o desactiva el modo rápido.

Escribir peticiones largas

  • \ y luego EnterUna línea nueva. Funciona en todas las terminales.
  • Ctrl+JUna línea nueva, sin configurar nada, en cualquier terminal.
  • Shift+EnterUna línea nueva. Funciona de serie en iTerm2, WezTerm, Ghostty, Kitty, Warp, Apple Terminal y Windows Terminal. Otras terminales necesitan un ajuste.
  • Ctrl+GAbre tu petición en tu editor de texto por defecto.
  • Ctrl+SAparta lo que estás escribiendo y deja la caja vacía. Púlsalo otra vez con la caja vacía para recuperar el texto.
  • Ctrl+V / Alt+VPega una imagen del portapapeles (Alt+V en Windows y WSL).

Empezar una petición con un símbolo

  • /Un comando o una skill. Escribe letras detrás para filtrar la lista.
  • !Modo terminal: ejecuta un comando directamente, añade su salida a la sesión y hace que Claude responda.
  • @Menciona un archivo, con autocompletado de rutas.
  • ?Con la caja vacía, muestra el panel de ayuda de atajos.

Mirar atrás y llevar el control

  • Ctrl+RBusca entre tus peticiones anteriores.
  • Ctrl+OAbre el visor de transcripción, con el uso detallado de herramientas, y la hora y el modelo de cada respuesta. También expande las líneas que van plegadas por defecto.
  • Ctrl+TMuestra u oculta la lista de tareas de Claude.
  • Ctrl+BManda a segundo plano los comandos de terminal y los agentes en marcha. Con tmux se pulsa dos veces.
  • Ctrl+LRedibuja la pantalla si se ve mal. Tu texto y la conversación se quedan.

Editar texto rápido

  • Ctrl+A / Ctrl+ESaltan al principio o al final de la línea.
  • Ctrl+K / Ctrl+UBorran hasta el final o hasta el principio de la línea. El texto borrado se guarda para pegarlo.
  • Ctrl+WBorra hacia atrás hasta el espacio anterior, así que una pulsación quita una ruta entera como src/utils/foo.ts.
  • Ctrl+YPega lo último que borraste con alguno de esos atajos.

Bueno saber

  • Los atajos varían según la plataforma y la terminal. En macOS, los atajos de palabra con Alt (Alt+B, Alt+F, Alt+D) necesitan que Option actúe como Meta en tu terminal.
  • Claude Code tiene un archivo para tus propios atajos, keybindings.json. Los atajos de edición por palabras de arriba no se pueden reasignar ahí. Para saber dónde está el archivo, mira la carpeta .claude explicada.
  • Algunos detalles dependen de tu versión. Mira la página de documentación de la tuya.

Pruébalo con algo inofensivo

  1. Escribe una frase larga, pulsa Esc dos veces y luego la flecha arriba para recuperarla.
  2. Pulsa ? con la caja vacía y lee el panel.
  3. Pulsa Ctrl+O una vez para ver el visor de transcripción y Esc para salir.
