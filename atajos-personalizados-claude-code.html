Personalizar los atajos de teclado de Claude Code

Puedes cambiar la mayoría de los atajos de Claude Code con un pequeño archivo JSON. Ejecuta /keybindings para crearlo o abrirlo en ~/.claude/keybindings.json. Los cambios se detectan solos, sin reiniciar. Para los atajos que existen por defecto, mira la guía de atajos.

El archivo

Es un objeto con una lista bindings. Cada bloque nombra un contexto (dónde se aplica el atajo) y asigna pulsaciones a acciones. Este ejemplo asigna Ctrl+E a abrir un editor externo en la entrada del chat y quita Ctrl+S:

{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "$docs": "https://code.claude.com/docs/en/keybindings",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "ctrl+s": null
      }
    }
  ]
}

$schema y $docs son opcionales; el esquema da autocompletado a tu editor.

Contextos

Un contexto es la parte de la aplicación donde un atajo está activo. Algunos habituales: Global (en todas partes), Chat (la entrada principal), Autocomplete (el menú está abierto), Confirmation (diálogos de permisos), Transcript, HistorySearch (Ctrl+R), Task (una tarea corre en primer plano), Select (listas genéricas) y Scroll (desplazamiento y selección en pantalla completa). La documentación lista más, y una larga tabla de nombres de acciones como chat:newline y chat:submit. Las acciones tienen la forma contexto:acción.

Cómo escribir una tecla

  • Une los modificadores con +: ctrl+k, shift+tab, ctrl+shift+c.
  • Nombres de modificadores: ctrl, shift, alt (también opt, option, meta: Alt en Windows y Linux, Option en macOS) y cmd (también super, win). La mayoría de terminales nunca envían el grupo cmd, así que usa ctrl o meta para los atajos que deban funcionar en todas partes.
  • Los nombres de teclas no distinguen mayúsculas. Para asignar Shift y una letra, escribe shift+k.
  • Teclas especiales: escape, enter, tab, space, las flechas, pageup, pagedown, home, end, backspace, delete.
  • Con una distribución que no sea la de EE. UU., escribe los atajos con Ctrl con letras latinas aunque tu distribución escriba otros caracteres.

Acordes

Un acorde es una secuencia separada por un espacio, como ctrl+k ctrl+s: pulsa la primera, suéltala y pulsa la segunda, cada una dentro de los 3 segundos de la anterior o Claude Code cancela el acorde.

Quitar un atajo por defecto

Pon la tecla a null, como ctrl+s en el ejemplo de arriba. Funciona también con acordes. Si quitas algunos acordes que comparten la primera tecla pero no todos, pulsar esa tecla sigue esperando al resto.

Lo que no se puede cambiar

Estos son fijos: Ctrl+C (interrumpir), Ctrl+D (salir), Ctrl+M (se recibe siempre como Enter), Ctrl+[ (como Escape), Ctrl+I (como Tab), Ctrl+H y Bloq Mayús. Algunos atajos además chocan con otras herramientas: Ctrl+B es el prefijo de tmux, Ctrl+A es el prefijo de GNU screen y Ctrl+Z suspende el proceso. Lo que tu terminal envía en primer lugar es otro asunto; mira configurar tu terminal.

Modo Vim

Si activas el modo vim, vim se ocupa del cursor y de los modos, y los atajos se ocupan de acciones como enviar un mensaje. Las teclas de vim no se pueden reasignar aquí; para convertir una secuencia de dos teclas como jj en Escape, la documentación remite al ajuste vimInsertModeRemaps.

Revisa tus errores

Claude Code escribe un aviso en el registro de depuración por errores de sintaxis, modificadores mal escritos, contextos o acciones no válidos, atajos reservados y asignaciones duplicadas. Arranca con claude --debug para verlos. Dos trampas de la documentación: un modificador mal escrito como ctl+k se descarta y el atajo se aplica solo a k, y un espacio junto al signo más, como en ctrl+ k, se lee como un acorde que nunca se dispara. Un nombre de acción desconocido salta tu asignación y mantiene la de por defecto para esa tecla. Si un cambio parece no hacer nada, mira depurar la configuración.
