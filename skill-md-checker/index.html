SKILL.md checker

Paste a SKILL.md and see why a Claude Code (or other agent) skill does not load, never triggers, or does something you would not want. It runs in your browser: nothing is uploaded or stored.

    What it checks
    • Frontmatter: the file starts with ---, closes it, and every line is key: value.
    • YAML traps: an unquoted : in the description (the most common silent failure: strict installers skip the skill without telling you), tabs, unclosed quotes, values that start with special characters, duplicated keys, # that cuts the line.
    • name: present, lowercase with hyphens, 64 characters or fewer, same as the folder, no reserved words.
    • description: present, 1024 characters or fewer, says what it does and when to use it, no tags, third person.
    • Body: not empty, under about 500 lines, no personal absolute paths, linked files exist (when you give the folder list).
    • Safety: curl | sh, rm -rf, sudo, reading .env or SSH keys, prompt-injection phrases, turning off permissions or hooks, encoded blobs, eval, unlimited Bash in allowed-tools.

    These are pattern checks, not a guarantee. A clean result means none of these problems were found; still read the whole file before you install a skill from someone else.
