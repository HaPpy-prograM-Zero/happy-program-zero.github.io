Guías para Claude Code

Páginas cortas que lees en pocos minutos. Cada una está escrita a partir de la documentación de Anthropic, dice lo que no probamos y enlaza a la fuente.

  • Diez comprobaciones para tu CLAUDE.mdUna lista corta para revisar el archivo que Claude Code lee en cada sesión.
  • Una nota de relevo de 40 líneasPara que una sesión nueva siga donde se quedó la anterior.
  • Cómo escribir un SKILL.mdDónde va, qué poner y cómo comprobar que carga.
  • Lista de partida de reglas de permisosAllow, ask y deny, dónde va cada archivo y lo que las reglas no hacen.
  • Tres hooks para pegarUn aviso, formato tras editar y bloqueo de archivos protegidos.
  • CLAUDE.md, skill, hook o subagenteCuál usar, qué cuesta cada uno en contexto y cuáles se aplican a la fuerza.
  • Escribe tu primer subagenteDónde va el archivo, los campos que importan y un ejemplo para pegar.
  • Gasta menos cuotaAdónde van los tokens, por qué una sesión larga cuesta más y qué hábitos ayudan.
  • Qué archivo de ajustes mandaDe dónde salen los ajustes, en qué orden ganan y cómo comprobar qué se cargó.
  • Añade tu primer servidor MCPUn comando, los tres ámbitos, el archivo .mcp.json y qué comprobar antes de fiarte de uno.
  • Deshacer cambios con /rewindCómo funcionan los puntos de control, qué hace cada opción y qué no puede deshacer.
  • Los modos de permisos, explicadosLos seis modos, cómo cambiar, cómo funciona el modo plan y por qué bypass es solo para máquinas aisladas.
  • Ejecutar Claude Code desde un scriptclaude -p: pasarle texto, salida en JSON, qué herramientas permitir, el modo bare y un aviso sobre repositorios que no escribiste tú.
  • La carpeta .claude explicadaQué hace cada archivo, cuáles subir a git y qué guarda Claude Code en tu disco y durante cuánto tiempo.
  • Atajos de teclado que merece la pena aprenderLos atajos que más tiempo ahorran: parar, deshacer, cambiar de modo, escribir peticiones largas, buscar en el historial y editar texto.
  • Cómo recuerda Claude Code tu proyectoCLAUDE.md frente a memoria automática: para qué sirve cada una, dónde vive y qué mirar cuando Claude la ignora.
  • Qué sobrevive a /compactQué hay en la ventana de contexto, qué le pasa a cada tipo de contenido cuando se compacta una sesión y qué hacer antes de que se llene.
  • Sesiones en paralelo con git worktreesDa a cada sesión de Claude Code su propia copia de tus archivos: la opción --worktree, qué se comparte, copiar un .env y la limpieza.
  • Personalizar la línea de estadoMonta una barra que muestre el modelo, el uso del contexto o la rama de git: el comando /statusline, un script mínimo y qué mirar cuando sale en blanco.
  • Depurar la configuraciónCuando Claude ignora tu CLAUDE.md, hooks, servidores MCP o skills: ver qué se cargó de verdad, repasar las causas habituales y probar con una configuración limpia.
  • Estilos de salidaCambia el tono, la extensión y el papel de las respuestas de Claude en toda una sesión: los cuatro estilos integrados, cómo cambiar y cómo escribir el tuyo.
  • Cómo funciona Claude CodeEl bucle que ejecuta, las herramientas que usa, lo que ve, cómo se comportan las sesiones y la ventana de contexto, y las redes de seguridad: un repaso en llano con enlaces a las guías largas.
  • Buenas prácticas, la versión cortaDile a Claude lo que no puede ver, dale una comprobación que ejecutar, haz cumplir las reglas sin excepciones y sabe qué dejar de hacer.
  • El sandboxQué cubre el sandbox y qué no, cómo activarlo con /sandbox, los dos modos, cómo ampliarlo o reducirlo y sus límites.
  • Instalar y gestionar pluginsCómo instalar un plugin, elegir alcance de usuario, proyecto o local, añadir un marketplace, mantener los plugins al día, quitarlos y ver lo que cuestan a tu contexto.
  • Arreglar una sesión lenta o atascadaMucha CPU o memoria, cuelgues, compactación que no acaba, texto raro, portapapeles vacío y búsquedas que no encuentran nada: los arreglos, en llano.
  • Configurar tu terminalShift+Enter para líneas nuevas, atajos con Option en macOS, un aviso cuando Claude termina, tmux, parpadeo, pegados grandes y teclas Vim: los arreglos de terminal, en llano.
  • Personalizar los atajosCómo cambiar atajos con keybindings.json: el archivo, los contextos, la sintaxis de teclas, los acordes, quitar uno por defecto, lo que no se puede cambiar y cómo ver los errores.
  • Flujos de cada díaPrompts y hábitos para el trabajo diario: entender un código, arreglar un fallo, refactorizar, escribir pruebas, abrir un PR, imágenes y referencias con @, retomar, planificar antes y programar ejecuciones.
  • Programar con /loopIntervalos fijos o elegidos por Claude, un loop.md por defecto, recordatorios de una vez, cómo parar un bucle, la caducidad de siete días, el jitter, la sintaxis cron y los límites.
  • Trabajar hacia un objetivo con /goalFijar una condición de fin, escribir una que un verificador pueda comprobar, acotarla con un límite de turnos, ver el estado, borrarla o retomarla, y qué detiene o pausa un objetivo.
  • Arreglar «command not found: claude»La instalación terminó pero la terminal no encuentra claude: comprobar el archivo, añadir su carpeta al PATH en macOS, Linux y Windows, abrir una terminal nueva, detectar instalaciones duplicadas y recuperar un claude.exe que falta.
  • Glosario en llanoLos términos que usa la documentación de Claude Code, explicados en una o dos frases: bucle agéntico, ventana de contexto, compactación, CLAUDE.md, skill, hook, subagente, MCP, modo de permisos, worktree, sesión en la nube y más.
  • Modo pantalla completa: parpadeo, scroll y copiarActivar o quitar el renderizado en pantalla completa con /tui, qué cambia en la búsqueda, el scroll y el copiado, la selección nativa, las rarezas de tmux y Windows Terminal y qué significa el aviso del arranque.
  • Comandos con barra que conviene conocerLos comandos con barra de Claude Code que de verdad se usan, agrupados por el momento en que los necesitas: primera sesión, durante una tarea, conversaciones largas, preguntas aparte, trabajo en paralelo, antes de entregar, entre sesiones y cuando algo falla.
  • Claude Code en VS CodeInstalar la extensión, abrir el panel, iniciar sesión, dar a Claude los archivos justos con @-menciones, revisar ediciones, reanudar o deshacer una conversación, los atajos que merecen la pena, extensión frente a CLI y qué probar cuando falta el icono Spark.
  • Claude Code en un monorepo o código grandeMantener a Claude enfocado en un repositorio grande: desde dónde arrancarlo, CLAUDE.md por capas, excluir los que nunca necesitas, bloquear la lectura de código generado y de terceros, un plugin de servidor de lenguaje, worktrees parciales y cómo planificar cambios que cruzan paquetes.
  • Claude Code en GitHub ActionsInstalación rápida y manual de la GitHub Action de Claude Code, los dos secretos y dónde van, menciones @claude frente a automatización con un prompt, quién puede activarla, cómo contener los costes, los arreglos habituales cuando no responde y cómo desinstalar limpiamente.
  • Sesiones de Claude Code: reanudar, nombrar y ramificarContinuar la última conversación, elegir una de una lista, reanudar por nombre, poner nombre a las sesiones para encontrarlas, ramificar una conversación para probar otro enfoque, qué restaura y qué no una sesión reanudada y dónde se guardan las transcripciones.
  • Claude Code en los IDE de JetBrainsInstalar la CLI y el plugin para IntelliJ, PyCharm, WebStorm y el resto, ejecutar claude en el terminal del IDE o conectar con /ide, el visor de diferencias y los atajos, los arreglos para ESC, WSL y desarrollo remoto, y una nota de seguridad sobre los permisos de edición.
  • Dictado por voz en Claude CodeDictar tus prompts en el terminal: los requisitos y el punto de privacidad (el audio va a los servidores de Anthropic), /voice, modo mantener frente a modo tocar, cancelar una grabación, el idioma del dictado, reasignar la tecla y los arreglos habituales cuando no graba.
