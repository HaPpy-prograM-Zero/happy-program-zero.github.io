Claude Code en VS Code: instalar, primer prompt y soluciones

La extensión de VS Code pone Claude Code en un panel junto a tu código, con diffs que puedes leer antes de aceptar. Por debajo es el mismo Claude Code, con algunas diferencias respecto a la versión de terminal que despistan. Aquí tienes el camino corto desde la instalación hasta un primer prompt útil, y qué comprobar cuando falta algo.

Antes de instalar

  • Un VS Code reciente. Según la documentación, tal como la leemos, el mínimo es 1.94.0. Mira Help > About si la extensión no aparece.
  • Una cuenta. Vale una suscripción de pago de Claude o una cuenta de Claude Console, y no necesitas clave de API. Inicias sesión desde el panel la primera vez que lo abres.
  • La extensión lleva su propia copia de la CLI. Esa copia solo mueve el panel de chat. No añade claude a tu PATH, así que escribir claude en una terminal sigue necesitando la instalación independiente (mira arreglar «command not found: claude»).

Instalar y abrir

  1. Pulsa Ctrl+Shift+X (Cmd+Shift+X en Mac), busca Claude Code y pulsa Install. También se instala en otros editores basados en VS Code, como Cursor; si alguno no puede instalarla, usa la CLI en la terminal de ese editor.
  2. Si después no aparece nada, reinicia VS Code o ejecuta Developer: Reload Window desde la paleta de comandos (Ctrl+Shift+P).
  3. Abre el panel con el icono Spark arriba a la derecha del editor. Ese icono solo sale con un archivo abierto. Otras entradas: el icono Spark de la barra de actividad (lista tus sesiones), la paleta de comandos (escribe «Claude Code») o ✻ Claude Code en la barra de estado, que funciona aunque no haya ningún archivo abierto.
  4. Pulsa Sign in y termina en el navegador. Si tienes ANTHROPIC_API_KEY en tu shell y aun así sale la pantalla de inicio de sesión, puede que VS Code no haya heredado tu entorno: arráncalo desde una terminal con code . o inicia sesión con tu cuenta.

Tu primer prompt

Pregunta como lo harías en la terminal: explícame esta función, busca por qué falla este test, haz este cambio. Dos cosas ayudan desde el principio:

  • Claude ve tu selección. Resalta código y la caja del prompt muestra cuántas líneas lleva adjuntas. También sabe qué archivo tienes abierto. Alt+K (Option+K en Mac) inserta una referencia con el archivo y las líneas, como @app.ts#5-10.
  • Mira el modo. El modo de permisos está abajo en la caja del prompt. En modo manual Claude muestra un diff lado a lado de cada edición propuesta y espera tu respuesta; en un modo automático edita sin preguntar; en modo plan escribe primero un plan y espera tu aprobación. El modo con el que empiezas puede cambiar según la versión y el plan, así que lee el indicador en vez de suponerlo. Detalles en modos de permisos.

Dale el contexto adecuado

  • @auth busca de forma aproximada un archivo o carpeta. Para una carpeta añade la barra final: @src/components/.
  • @terminal:nombre trae la salida de una terminal por su título, así no copias y pegas errores.
  • Pega una imagen desde el portapapeles para adjuntarla, o mantén Shift mientras arrastras archivos a la caja.
  • Shift+Enter añade una línea nueva sin enviar.
  • ¿No quieres que se adjunte tu selección o el archivo abierto en cada mensaje? Hay ajustes de la extensión para desactivar Attach Selection y Attach Open File.

Reanudar, deshacer, bifurcar

  • El historial de sesiones, el botón de arriba del panel, te deja buscar y reabrir conversaciones antiguas. Las inactivas se archivan solas pasado un tiempo, y puedes desarchivarlas.
  • La extensión y la CLI comparten un único historial. Para seguir en una terminal una conversación de la extensión, ejecuta claude --resume y elígela.
  • Deshacer: pasa el ratón sobre un mensaje y pulsa el botón de rebobinar. Puedes bifurcar la conversación desde ahí, devolver el código a ese punto, o las dos cosas. Mira deshacer cambios con rewind.

Atajos que merecen la pena

  • Ctrl+Esc (Cmd+Esc en Mac) alterna el foco entre el editor y Claude.
  • Ctrl+Shift+Esc abre una conversación nueva como pestaña del editor.
  • Ctrl+N empieza una conversación nueva, pero solo con el foco en Claude y con el ajuste enableNewConversationShortcut activado.
  • Todo lo demás está en la paleta de comandos: escribe «Claude Code» para listar los comandos de la extensión.

¿Extensión o CLI?

Según la documentación, tal como la leemos, la extensión admite un subconjunto de comandos y skills (escribe / para ver los tuyos), y algunas comodidades de la terminal son solo de la CLI, como el atajo ! para el shell y el autocompletado con tabulador. Para usar la CLI completa sin salir de VS Code, abre la terminal integrada con Ctrl+` (Cmd+` en Mac) y ejecuta claude; se conecta al editor para los diffs y los diagnósticos. Desde una terminal externa, ejecuta /ide para conectarla con VS Code. Mira también los comandos con barra que conviene conocer y la guía de la terminal.

Cuando falta algo

  • No hay icono Spark: abre un archivo (una carpeta sola no basta), comprueba la versión de VS Code, ejecuta Developer: Reload Window, desactiva un momento otras extensiones de IA que puedan chocar y asegúrate de que el espacio de trabajo es de confianza, porque la extensión no funciona en Restricted Mode. El botón de la barra de estado y la paleta de comandos funcionan sin él.
  • La extensión no se instala: versión compatible de VS Code, permiso para instalar extensiones, o prueba desde la página del Marketplace.
  • Cmd+Esc no hace nada en Mac: un macOS reciente reserva esa tecla para el Game Overlay. Quita ese atajo en Ajustes del Sistema o reasigna Claude Code: Focus input en el editor de atajos de VS Code.
  • Errores como «Could not locate the Claude CLI on PATH», un 403 tras iniciar sesión o errores de certificado: la documentación tiene una tabla que lleva cada mensaje a su arreglo, así que busca allí el texto exacto.
  • Una sesión atascada o lenta: Show Logs en la paleta de comandos muestra los registros de depuración de la extensión.
