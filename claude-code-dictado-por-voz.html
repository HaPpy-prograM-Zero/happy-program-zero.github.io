Dictado por voz en Claude Code: activarlo, modos, idiomas y arreglos

Puedes dictar tus prompts a Claude Code en vez de escribirlos. Tu voz se convierte en texto en directo dentro del prompt, así que puedes mezclar hablar y teclear en el mismo mensaje. Aquí tienes cómo activarlo, qué modo elegir y qué mirar cuando no graba.

Antes de empezar: los requisitos

  • Tu audio sale de tu equipo. El dictado envía la grabación a los servidores de Anthropic para transcribirla; nada se transcribe en local. Si eso es un problema para lo que vas a decir, no lo uses, y lee la página de uso de datos de la documentación.
  • Necesitas iniciar sesión con Claude.ai. Según la documentación, tal como la leemos, no está disponible cuando Claude Code usa una clave de API directamente o funciona a través de Amazon Bedrock, Agent Platform de Google Cloud o Microsoft Foundry.
  • Necesitas un micrófono en el mismo equipo. No funciona en sesiones en la nube ni por SSH. En WSL hace falta WSL2 con WSLg. La extensión de VS Code también lo admite, pero no en las sesiones remotas de VS Code (SSH, Dev Containers, Codespaces), porque el micrófono está en tu equipo y la extensión se ejecuta en otro sitio.
  • La transcripción no gasta mensajes ni tokens de Claude y no cuenta para los límites que muestra /usage.

Activarlo

Ejecuta /voice. Claude Code hace una comprobación del micrófono y, en un Mac, tu terminal puede pedirte permiso de micrófono. Puedes añadir un modo: /voice hold, /voice tap o /voice off. La elección se recuerda entre sesiones. También puedes fijarlo en tus ajustes de usuario con un bloque voice (enabled y mode). La transcripción está afinada para palabras de programación como regex, OAuth, JSON y localhost, y toma el nombre de tu proyecto y de tu rama como pistas.

¿Mantener o tocar?

  • Modo mantener (el predeterminado) es pulsar para hablar: mantén Espacio mientras hablas y suéltalo para parar. Hay un breve calentamiento porque Claude Code detecta una tecla mantenida mirando la repetición de tecla. El texto aparece atenuado en el prompt y luego se asienta. Al soltar, espera a que pulses Enter, salvo que pongas autoSubmit en true, que lo envía si la transcripción tiene al menos tres palabras.
  • Modo tocar (/voice tap): toca Espacio con el prompt vacío para empezar y vuelve a tocar para parar y enviar. No hay calentamiento. Las transcripciones de menos de tres palabras se insertan pero no se envían, así que un toque suelto no manda una palabra al azar. La grabación también se para tras 15 segundos de silencio o dos minutos en total.
  • Para evitar el calentamiento del modo mantener, usa el modo tocar o reasigna la tecla a una combinación con modificador (abajo).

Cancelar una grabación

Pulsa Esc o Ctrl+C para cancelar un dictado: para el micrófono, descarta la transcripción y deja tu prompt como estaba. Ninguna de las dos teclas hace otra cosa en esa pulsación, así que Esc no interrumpirá la respuesta de Claude y Ctrl+C no borrará el prompt.

Idioma

El dictado sigue el mismo ajuste language que las respuestas de Claude, que se cambia en /config o en los ajustes (por nombre, como «spanish», o por código de idioma). Si está vacío, el dictado usa inglés, así que si el texto sale ininteligible, fija primero el idioma. La documentación lista los idiomas admitidos, entre ellos español, francés, alemán, portugués, italiano, neerlandés, japonés y coreano; comprueba esa lista para el tuyo, porque un idioma no admitido vuelve al inglés para el dictado (las respuestas escritas de Claude no se ven afectadas).

Reasignar la tecla

La tecla es la acción voice:pushToTalk en el contexto Chat, y sustituye a Espacio cuando asignas otra. Una combinación con modificador como meta+k empieza a grabar a la primera pulsación y sin calentamiento. En el modo mantener, evita una letra suelta, porque la letra se escribe en el prompt durante el calentamiento. Algunas teclas, como Bloq Mayús, nunca llegan a los programas de terminal y no se pueden asignar. Más en personalizar los atajos de teclado.

Cuando no funciona

  • «Unknown command: /voice»: no has iniciado sesión con una cuenta de Claude.ai, o una clave de API o un proveedor externo tiene prioridad. Ejecuta /login y quita la otra credencial.
  • «Microphone access is denied»: permite tu terminal en los ajustes de privacidad de micrófono del sistema y vuelve a ejecutar /voice. Si un terminal de Mac no aparece en esa lista, la documentación tiene un procedimiento de reinicio; usa el comando exacto que da y evita reiniciar el permiso de micrófono de todas las aplicaciones.
  • Linux: si el grabador integrado no carga, Claude Code recurre a arecord o rec e imprime un comando de instalación cuando no existe ninguno. En WSL, SoX necesita su componente de PulseAudio; la documentación da los nombres de los paquetes.
  • No pasa nada al mantener Espacio: si se acumulan espacios, el dictado está apagado, así que ejecuta /voice hold. Si solo aparecen uno o dos espacios, tu terminal no envía repetición de tecla; pasa al modo tocar.
  • «No audio detected» o «No speech detected»: comprueba que el dispositivo de entrada correcto es el predeterminado del sistema y no está silenciado, habla más cerca y asegúrate de que el idioma del dictado coincide con el tuyo.
  • Errores de conexión o de certificado: revisa tu red. Detrás de un proxy que inspecciona TLS, la documentación remite a la página de VS Code para el arreglo. Una conexión rechazada suele indicar un inicio de sesión caducado, así que prueba /login.
