Deshacer lo que hizo Claude Code con /rewind

Claude editó los archivos equivocados o se fue por un camino que no quieres. Claude Code guarda puntos de control mientras trabajas, así que puedes dar un paso atrás sin rebuscar entre tus archivos. Tiene límites, y conviene conocerlos antes de necesitarlo.

Cómo funcionan los puntos de control

  • Cada petición que envías y que inicia un turno crea un punto de control de tu código tal como estaba antes de ese turno.
  • Claude Code sigue los cambios hechos con sus propias herramientas de edición de archivos.
  • Conserva copias de los archivos de los 100 puntos de control más recientes de una sesión.
  • Los puntos de control se guardan con la conversación, así que /rewind sigue funcionando cuando retomas una sesión.
  • Por defecto las copias se limpian unos 30 días después de la última vez que la sesión guardó una. El ajuste cleanupPeriodDays lo cambia.

Abre el menú

Escribe /rewind, o pulsa Esc dos veces cuando la caja de texto esté vacía. Si la caja tiene texto, el doble Esc lo borra en lugar de abrir el menú, y puedes recuperarlo con la flecha arriba. El menú lista las peticiones que enviaste en esta sesión. Elige el punto que quieras y después una acción.

Las acciones

  • Restore code and conversationRevierte las dos cosas a ese punto.
  • Restore conversationRebobina el chat hasta ese mensaje y deja el código como está ahora.
  • Restore codeRevierte los cambios en los archivos y conserva la conversación.
  • Summarize from hereComprime la conversación desde ese punto en adelante en un resumen, lo que libera espacio en la ventana de contexto.
  • Summarize up to hereComprime lo anterior a ese punto y conserva los mensajes posteriores.
  • Never mindVuelve a la lista sin cambiar nada.

Las dos opciones de código solo aparecen si el punto elegido tiene cambios de archivos registrados. Tras restaurar o tras «Summarize from here», la petición original vuelve a la caja de texto para que la edites y la envíes otra vez.

Resumir no toca tus archivos, y los mensajes originales siguen en la transcripción de la sesión. Para dirigir el resumen, resalta una opción Summarize y escribe instrucciones donde dice «add context (optional)». Si ejecutaste /clear antes en el mismo proceso de Claude Code, el menú muestra además arriba una entrada /resume para la sesión anterior al borrado.

Cuándo sirve

  • Quieres probar un segundo enfoque sin perder el punto de partida.
  • Un cambio metió un error y quieres quitarlo.
  • Una sesión larga de depuración se come el contexto y quieres comprimir el tramo del medio. Mira gasta menos cuota.

Para ramificar y probar algo distinto manteniendo entera la sesión original, la documentación recomienda /branch o claude --continue --fork-session en lugar de rebobinar.

Lo que no puede deshacer

  • Cambios hechos solo por un comando de terminal. Si Claude ya había editado un archivo con sus herramientas de edición, rewind también deshace los cambios posteriores de terminal sobre ese archivo. Un archivo que solo cambiaron comandos de terminal no se sigue. Usa git.
  • La mayoría de ediciones de subagentes. Rewind restaura solo los archivos que Claude ya había editado en tu conversación. Las ediciones de un subagente en otros archivos se quedan. Usa git.
  • Cambios de fuera. Lo que edites a mano fuera de Claude Code y lo que hagan otras sesiones a la vez normalmente no se registra.
  • Un mensaje que escribiste mientras Claude trabajaba puede aparecer marcado como «No code restore». Para deshacer esas ediciones, rebobina a la petición que inició el turno.
  • Enlaces simbólicos y enlaces duros. Claude Code los salta y muestra un aviso de «skipped». Pídele a Claude que revierta la edición, o edita tú el archivo.

No es control de versiones

La documentación dice que los puntos de control sirven para recuperarte rápido dentro de una sesión. Para un historial fiable y para trabajar con otras personas, sigue haciendo commits en git. Un buen hábito es hacer un commit antes de empezar algo grande.

Pruébalo con algo inofensivo

  1. En una carpeta de pruebas, pide a Claude que cree un archivo pequeño.
  2. Escribe /rewind, elige la petición y elige «Restore code».
  3. Comprueba que el archivo ya no está y que la conversación sigue ahí.
