Configurar tu terminal para Claude Code

Claude Code funciona en cualquier terminal sin configurar nada. Esta página es para cuando algo concreto va mal: Shift+Enter envía tu mensaje, los atajos con Option no hacen nada, no te enteras de cuándo acaba una tarea larga o la pantalla parpadea. Busca tu síntoma y sáltate el resto.

Shift+Enter envía en vez de añadir una línea

Enter envía tu mensaje. Para añadir un salto de línea sin enviar, pulsa Ctrl+J, o escribe \ y pulsa Enter. Las dos formas funcionan en cualquier terminal sin configurar nada. Shift+Enter también funciona en muchas terminales, pero depende de la que uses:

  • Sin configurar nada: Ghostty, Kitty, iTerm2, WezTerm, Warp, Apple Terminal y Windows Terminal. Las terminales que admiten el protocolo de teclado de kitty, como foot y las Alacritty recientes, también funcionan con una versión de Claude Code suficientemente reciente.
  • Ejecuta /terminal-setup una vez: VS Code, Cursor, Zed y Alacritty antiguas. Escribe un atajo de Shift+Enter en el archivo de configuración de la terminal y respeta los que ya existen. Ejecútalo en la propia terminal anfitriona, no dentro de tmux o screen.
  • No disponible: gnome-terminal y los IDE de JetBrains como PyCharm. Usa Ctrl+J o \ y Enter.

En VS Code y Cursor, /terminal-setup también apaga la aceleración por GPU del editor para la terminal, lo que evita el texto distorsionado (mira arreglar una sesión lenta o atascada). Para que Enter inserte una línea y Shift+Enter envíe, asigna las acciones chat:newline y chat:submit en tu archivo de atajos; la guía de atajos tiene lo básico.

Los atajos con Option no hacen nada en macOS

Algunos atajos usan Option, como Option+Enter para una línea nueva u Option+P para cambiar de modelo. La mayoría de terminales de macOS no envían Option como modificador por defecto; el ajuste suele llamarse «Use Option as Meta Key».

  • Apple Terminal: Ajustes, Perfiles, Teclado, marca «Use Option as Meta Key».
  • iTerm2: Ajustes, Profiles, Keys, General, pon las dos teclas Option en «Esc+».
  • VS Code: añade "terminal.integrated.macOptionIsMeta": true a sus ajustes.

Otras terminales tienen un ajuste de Option como Alt o como Meta en su propia configuración.

Un sonido o aviso cuando Claude termina

Cuando Claude termina o se para a pedir permiso y pareces estar lejos, lanza un evento de notificación. Por defecto Ghostty, Kitty e iTerm2 reciben una notificación de escritorio (iTerm2 solo cuando activas sus ajustes de alertas), Apple Terminal recibe en algunos casos un carácter de campana silencioso y las demás terminales no reciben nada. Para enviar el carácter de campana en cualquier terminal, pon esto en ~/.claude/settings.json:

{
  "preferredNotifChannel": "terminal_bell"
}

En Apple Terminal activa además «Audible bell» en Ajustes, Perfiles, Avanzado para oírla. Para un sonido o un comando propio en cualquier terminal, usa un hook de Notification; los hooks se ejecutan junto a la notificación incluida. La notificación de escritorio llega también a tu equipo local por SSH. Si aun así no aparecen, comprueba que tu aplicación de terminal tiene permiso de notificaciones en tu sistema operativo.

Dentro de tmux

Por defecto dentro de tmux, Shift+Enter envía, y las notificaciones de escritorio y la barra de progreso no llegan a la terminal exterior. Añade estas líneas a ~/.tmux.conf y ejecuta tmux source-file ~/.tmux.conf:

set -g allow-passthrough on
set -g focus-events on
set -s extended-keys on
set -as terminal-features 'xterm*:extkeys'

La primera línea deja pasar las notificaciones y el progreso. Las líneas de extended-keys permiten a tmux distinguir Shift+Enter de Enter.

Retroceso borra una palabra entera en Windows

En Windows, Claude Code lee como Ctrl+Retroceso un Retroceso que llega como ^H, y eso borra la palabra anterior. Si cada pulsación borra una palabra, pon la variable de entorno CLAUDE_CODE_BS_AS_CTRL_BACKSPACE=0. Si en cambio Ctrl+Retroceso borra un solo carácter en macOS o Linux, ponla a 1.

Colores y parpadeo de pantalla

Usa /theme (o el selector de /config) para ajustarlo a tu terminal; la opción automática sigue tu fondo claro u oscuro. Si la pantalla parpadea o el desplazamiento salta mientras Claude trabaja, ejecuta /tui fullscreen, que guarda la elección. Después te desplazas con el ratón o con RePág dentro de Claude Code y no con el historial de tu terminal. El mismo cambio está disponible como CLAUDE_CODE_NO_FLICKER=1, en tu shell o en el bloque env de settings.json (mira qué archivo de ajustes manda). En una ventana muy ancha, maxProseWidth en tus ajustes ajusta la prosa de Claude a un número fijo de columnas.

Pegados grandes

Pegar más de 800 caracteres o más de tres líneas contrae la entrada en un marcador como [Pasted text #1 +120 lines], y el contenido completo se envía igualmente al enviar. Para archivos enteros o registros largos, escribe el contenido en un archivo y pide a Claude que lo lea. La terminal integrada de VS Code también puede perder caracteres en pegados muy grandes, así que usa un archivo ahí. La documentación dice además que a Claude se le avisa de que un texto pegado puede contener instrucciones que no escribiste y que las siga solo donde tu propio mensaje se lo pida.

Teclas Vim en el prompt

Actívalo en /config en Editor mode, o pon "editorMode": "vim" en ~/.claude/settings.json. Cubre un subconjunto de movimientos y operadores de Vim. A diferencia del Vim estándar, Enter sigue enviando en modo INSERT; usa o u O en modo NORMAL, o Ctrl+J, para una línea nueva.

También puedes mostrar el modelo, la carpeta y la rama de git al pie de la pantalla con una línea de estado personalizada. Todas las guías están en el índice de guías.
